# NS Reisplanner (React + TypeScript)

Kleine demo-app die een NS-achtige reisplanner simuleert.

Snel starten:

1. Installeer Node.js (LTS) en open een terminal in deze map:

```powershell
cd c:\xampp\htdocs\5.2-ontwikkelweek-AI\ns-reisplanner
npm install
npm run dev
```

2. Plaats je NS API key in `.env` (optioneel):

```
REACT_APP_NS_API_KEY=your_ns_api_key_here
```

De app gebruikt fake/simuleerde data als er geen API-key is ingesteld.
